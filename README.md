# Valcohr CRM OS — Releases

Este repositorio público distribuye los instaladores oficiales de **Valcohr CRM OS para Ramiara**.

## Descargar

Abrí la sección [Releases](https://github.com/valcohr-analytics/valcohr-crm-os-releases/releases) y descargá el instalador correspondiente a tu sistema operativo. Cada versión incluye el manual del usuario y la guía de instalación.

- **Windows:** `Valcohr CRM OS - Ramiara <versión> Setup.exe`
- **Linux:** `Valcohr CRM OS-<versión>.AppImage`

La aplicación también consulta los metadatos de actualización publicados en cada release.

## Código fuente

Este repositorio contiene archivos de distribución y documentación de descarga. El código fuente se mantiene en un repositorio privado de Valcohr Analytics.
