# Valcohr CRM OS — Releases

Este repositorio distribuye los instaladores, archivos de actualización y
documentos de ayuda de Valcohr CRM OS. **El código fuente es privado** y no se
publica aquí.

## Descargar

[Ver la última versión disponible](https://github.com/valcohr-analytics/valcohr-crm-os-releases/releases/latest)

En cada release elegí el archivo de tu sistema:

- **Windows 64 bits:** `Valcohr-CRM-OS-X.Y.Z-Setup.exe`.
- **Linux 64 bits:** `Valcohr-CRM-OS-X.Y.Z.AppImage`.

También se incluyen los manifiestos de auto-update, `checksums.txt`, el manual
del usuario y la guía de instalación en PDF.

## Requisitos

- Windows 10 o posterior, 64 bits; o Linux de 64 bits (Ubuntu 22.04, Debian
  12 o equivalente).
- 4 GB de RAM y 500 MB de espacio disponible como mínimo.

## Instalación en Windows

Los instaladores no están firmados digitalmente. Windows puede mostrar
SmartScreen o “Editor desconocido”. Verificá que la descarga provenga de esta
organización y consultá la guía incluida en cada release antes de continuar.

## Actualizaciones y datos

La aplicación permite buscar actualizaciones desde **Configuración → Acerca
de**. Los datos de trabajo se guardan localmente en el equipo; trasladarlos a
otra computadora requiere crear y restaurar un backup.
